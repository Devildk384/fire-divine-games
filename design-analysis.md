# Fire Divine Games redesign — reference analysis

## Goal

Turn Fire Divine from a text-heavy studio page into a **game-first mobile studio brand** where visitors understand the games within seconds.

## What to borrow from the references

### SayGames
- Giant editorial headline and punchy short copy.
- The portfolio is the product: games and studio proof are placed ahead of long company explanations.
- Strong use of large numbers and concise calls to action.
- Asymmetrical blocks create momentum without needing a complicated UI.

### Supercell
- Very small number of top-level navigation choices.
- Games receive large visual real estate.
- Company philosophy is communicated with short, memorable statements rather than long paragraphs.
- Black/white foundations let individual game artwork carry the color.

### Miniclip
- Clear separation between featured titles, broader portfolio and studio updates.
- Familiar cards make a large game catalog easy to scan.
- News/careers modules give the studio site reasons to stay current after launch.

## Fire Divine-specific decisions

### 1. Hero = one game + one positioning line
The current concept opens with **“Games worth getting lost in.”** and uses Find Me as the lead visual. This makes the site feel like a game studio before a visitor reads any About copy.

### 2. Portfolio before history
A new visitor should see playable products before a studio timeline. Four representative titles are visible directly on the homepage, followed by a Google Play portfolio CTA.

### 3. Keep studio copy short
The long founder/history narrative is reduced to two paragraphs. A separate About page can contain the full story later.

### 4. Make Fire Divine visually recognizable
The concept uses an ink/off-white foundation, a bright acid-lime action color and a purple contact section. Individual games retain their own accent colors.

### 5. Mobile first
The design collapses into a one-column layout, retains large artwork, uses a compact mobile menu and keeps buttons thumb-friendly.

## Homepage information architecture

1. Floating navigation
2. Hero + featured game
3. Studio proof points
4. Genre ticker
5. Games portfolio
6. Studio positioning
7. Studio updates / content rhythm
8. Brand manifesto
9. Contact CTA
10. Footer

## Phase 2 recommendation

Create individual game pages with:
- key art / trailer
- 3–5 screenshots
- short feature bullets
- Google Play / App Store CTAs
- privacy/support link
- related games

This keeps the homepage light while giving each title enough room to convert visitors into players.
